How this works

  1. Paste your markdown or content into the box.
  2. Click Chunk it.
  3. Your text will be split into boxes, one for each heading, paragraph, or list.
  4. The tool expects blank lines between each chunk of items on the page, including between a heading and its paragraph.
  5. Headings are labeled with hashtags, e.g. # Heading 1, ## Heading 2, etc.
  6. Lists are labeled with dashes, asterisks, or numbers and a dot, e.g. - item 1, * item 2, 3. numbered item three
  7. If your text doesn't match that format, edit it here first.
  1. Each box is one piece of your page.
  2. Need to split a box? Click [Back], add a blank line where you want the split, and then chunk it again. Going back may erase edits you've made here, so do the big chunking first.
  3. Use the first dropdown on each box to change its type (heading, list, paragraph). Use the second dropdown to add dressing (callout, accordion). Full preview is on page 4.
  4. Spot a typo or vague link? Click [pencil] to edit that box's content, then click [check mark] when you're done.
  5. Fix any issues listed below. When the list says "Nothing to fix," you've cleared everything this tool checks for.
