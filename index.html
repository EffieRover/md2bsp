How this works

  1. Paste your markdown into the box.
  2. Click Chunk it.
  3. Your text is split into boxes, one for each heading, paragraph, or list.
  1. Each box is one piece of your page.
  2. Need to split a box? Click Back, add a blank line where you want the split, and chunk it again.
  3. Use the dropdown on each box to change what it is (heading, list, paragraph). The preview shows how it will look.
  4. Be sure to fix any accessibility or best practice issues listed below.
